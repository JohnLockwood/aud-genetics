# Project governance and learning workflow

**Date:** 2026-09-06  
**Author:** Project owner with Codex (GPT-5) assistance  
**Session type:** Project design and governance

## Prompts / scope

The project owner requested a preliminary working agreement for an AUD-genetics project that prioritizes advanced teaching, careful handling of potentially protected human genomic data, and durable Markdown records of tutorials and research sessions.

## Decisions

* The AI collaborator’s primary role is tutor and methodological partner. Substantial code is generated on request; short tutorial examples remain appropriate.
* This repository is limited to public, aggregate, synthetic, and non-sensitive materials. It is not an approved location for controlled-access individual-level human genomic or phenotype data.
* Any future controlled-data work requires an approved access plan and use only of the computing environment authorized by the relevant data-use agreement. Such data must not be included in AI prompts or repository notes.
* `SYLLABUS.md` is the course-level record and `notes/INDEX.md` is the chronological record. Material sessions use the reporting template.

## Sources consulted

* [NIH Security Best Practices for Controlled-Access Data](https://dbgap.ncbi.nlm.nih.gov/projects/gap/pdf/dbgap_2b_security_procedures.pdf) (accessed 2026-09-06).

## Limitations and next lesson

This is a project policy, not legal, institutional-review, or data-access advice. Before selecting a controlled dataset, identify its data-use limitations, access requirements, and approved storage/compute environment. The next lesson is a data-classification and public-data options review.
